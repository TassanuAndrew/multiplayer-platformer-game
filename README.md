# 🎮 Multiplayer Platformer Game with Chat System

**Socket Programming Project**

## 📖 Overview
Real-time multiplayer platformer with chat system using Python & Pygame

## ✨ Features
- Socket Programming (TCP/IP)
- Real-time multiplayer
- Live chat system
- 5 challenging levels

## 🚀 Quick Start

**Install:**
```
pip install pygame
```

**Run Server:**
```
python server.py
```

**Run Client:**
```
python main.py
```

## 🎮 Controls
- A/D: Move
- SPACE: Jump
- ENTER: Chat
- TAB: Toggle chat
